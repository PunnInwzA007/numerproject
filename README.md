# 🧮 NumerProject - Trapezoidal Integration Calculator

โปรแกรมคำนวณการอินทิเกรตเชิงตัวเลขด้วยวิธี **Composite Trapezoidal Rule** ออกแบบและพัฒนาด้วยหลักการเขียนโปรแกรมเชิงวัตถุ (**OOP**) แบบจัดเต็ม

โปรเจกต์นี้ส่งในรายวิชา **040613204 Object-Oriented Programming** ภาควิชาวิทยาการคอมพิวเตอร์และสารสนเทศ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ (มจพ.)

### ✨ What's inside?
- **OOP Architecture:** แยกโครงสร้างชัดเจนระหว่างคลาสจัดการโจทย์ (`Problem`) และคลาสตัวประมวลผล (`ProblemSolver`) โดยใช้หลัก Inheritance, Composition และ Polymorphism
- **Step-by-Step UI:** กดคำนวณปุ๊บ แสดงตารางและขั้นตอนวิธีทำ (Step Size $h$, ตาราง $f(x_i)$ และสูตรแทนค่า) ออกมาเป็นสมการ LaTeX สวยๆ ด้วย KaTeX
- **Tech Stack:** HTML5, Tailwind CSS, JavaScript (ES6+), Math.js และ KaTeX
